# Revision Notes — Williams Obstetrics, 26th Edition

Condensed, exam-focused notes for each chapter, kept separate from the full chapter texts in `chapters/`.

Each note includes:
- High-yield facts and numbers, grouped by the chapter's own sections
- **Tables transcribed from the PDF.** In the source PDF the tables are images, so they are missing from the extracted chapter texts, the audiobooks and the videos.
- **Figures from the PDF** placed beside the relevant sections (`images/chNN/`)
- Quick-recall summaries ("what goes up / down / unchanged") and key numbers

## Revision videos

`scripts/make_revision_video.py` turns a note into a narrated 1080p slide video. Bullets appear as they are read, tables are redrawn with rows revealed one at a time, and figures are shown with their captions. Output goes to `videos/revision/` (MP4 with a subtitle track, plus an `.srt`).

```bash
.revision_work/venv/bin/python scripts/make_revision_video.py Chapter_04_Maternal_Physiology
.revision_work/venv/bin/python scripts/make_revision_video.py Chapter_04_Maternal_Physiology --rate "+15%"
```

Requires `edge-tts`, `Pillow`, `fonttools` and ffmpeg.

## Rebuilding the PDFs

```bash
python3 scripts/build_revision_pdf.py            # all notes
python3 scripts/build_revision_pdf.py Chapter_04_Maternal_Physiology
```

Requires `pip install markdown` and `brew install weasyprint`.
